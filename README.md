# EliteA-Capstone

Key Features of Book Inventory System
•  Dashboard Analytics & KPIs:
•	Total Titles & Total Stock Copies tracking.
•	Real-time Total Stock Financial Valuation calculation ($).
•	Low Stock Alerts counter for items requiring reordering.
•  Inventory Management (CRUD):
•	Add New Book: Enter details such as Title, Author, ISBN, Genre, Price, Quantity in stock, and Cover image URL.
•	Edit Book: Update pricing, stock levels, or details dynamically.
•	Delete Book: Remove titles with confirmation alerts.
•  Search & Filters:
•	Live Search Bar: Search across Titles, Authors, or ISBN numbers instantaneously.
•	Genre Filter: Filter by Fiction, Non-Fiction, Technology, Science Fiction, Business, etc.
•	Stock Status Filter: Isolate In Stock (>5), Low Stock (1–5), and Out of Stock (0) titles.
•  Dual Display Views:
•	Switch between Card Grid View (with visual cover preview badges) and Table View (compact list format).
•  Data Persistence & Export:
•	Saved locally in the browser via localStorage (data persists on reload).
•	Export to JSON feature to export inventory data.
